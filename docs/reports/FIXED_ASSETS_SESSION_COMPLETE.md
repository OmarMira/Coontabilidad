## 🔗 USER WORKFLOWS ENABLED

### Asset Management
```
Create Asset:
Dashboard → "Nuevo Activo" → AssetForm → Save → Dashboard

View/Edit Asset:
Dashboard → Click Row → AssetDetailView → "Editar" → AssetForm → Save

Dispose Asset:
Dashboard → Click Row → AssetDetailView → "Disponer" → AssetDisposalForm → Confirm

Search/Filter:
Dashboard → Search/Filter → View Results → Click Asset
```

### Reporting
```
Asset Register:
Dashboard → Reports Tab → "Registro de Activos" → Filter → Export CSV

Depreciation Schedule:
Dashboard → Reports Tab → "Calendario de Depreciación" → Select Range → Export CSV

Disposal Summary:
Dashboard → Reports Tab → "Resumen de Disposiciones" → Select Year → Export CSV
```
