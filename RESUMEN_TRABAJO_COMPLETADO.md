## 🚀 CÓMO USARLO

### Paso 1: Iniciar Aplicación
```bash
npm run dev
```

### Paso 2: Navegar a Auditoría
1. Abrir menú lateral
2. Hacer clic en **"HERRAMIENTAS"**
3. Seleccionar **"Auditoría del Sistema"** (tiene badge "NEW")

### Paso 3: Ejecutar Auditoría
1. Hacer clic en **"Ejecutar Auditoría"**
2. Esperar 5-10 segundos
3. Revisar resultados

### Paso 4: Revisar Resultados
- **Resumen**: Ver estadísticas generales
- **Problemas Críticos**: Si existen, aparecen destacados
- **Resultados por Categoría**: Expandir para ver detalles

### Paso 5: Descargar Reporte
1. Hacer clic en **"Descargar Reporte HTML"**
2. Abrir archivo HTML en navegador
3. Guardar para documentación

### Paso 6: Corregir Problemas
1. Priorizar por severidad (Critical → High → Medium)
2. Corregir uno por uno
3. Re-ejecutar auditoría
4. Verificar que problemas se resolvieron
