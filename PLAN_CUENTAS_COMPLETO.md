## 🧪 Cómo Verificar

Después de limpiar storage y recargar:

```javascript
const db = window.db;

// Contar cuentas totales
const total = db.exec("SELECT COUNT(*) FROM chart_of_accounts");
console.log('Total cuentas:', total[0].values[0][0]); // Debería ser 115

// Ver cuentas por tipo
const byType = db.exec(`
  SELECT account_type, COUNT(*) as count 
  FROM chart_of_accounts 
  GROUP BY account_type
`);
console.table(byType[0].values.map(row => ({
  Tipo: row[0],
  Cantidad: row[1]
})));

// Ver estructura de activos
const assets = db.exec(`
  SELECT account_code, account_name 
  FROM chart_of_accounts 
  WHERE account_type = 'asset' 
  ORDER BY account_code
`);
console.table(assets[0].values.map(row => ({
  Código: row[0],
  Nombre: row[1]
})));
```
