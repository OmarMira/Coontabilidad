# MotorFiscal Skill (Florida Tax Engine)

**Propósito**: Automatizar el cálculo exacto de Sales Tax y Discretionary Sales Surtax para los 67 condados de Florida, cumpliendo con las tasas impositivas vigentes.

## Capacidades

- **Cómputo Multi-Condado**: Soporta tasas variables según la ubicación del cliente.
- **Cumplimiento Fiscal**: Asegura que el reporte DR-15 generado sea preciso.

## Uso

### Tasas de Ejemplo

- Miami-Dade: 7%
- Broward: 7%
- Orange: 6.5%
- Default (Base): 6%
