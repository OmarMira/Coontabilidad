## 🎓 LECCIONES APRENDIDAS

### Técnicas
1. **Auto-refresh**: Polling cada 30s mantiene UI actualizada
2. **Threshold Detection**: 3x promedio es buen balance
3. **Scheduler**: setInterval simple pero efectivo
4. **Conditional Rendering**: Solo mostrar si hay datos
5. **Dynamic Imports**: Lazy loading para IA

### Arquitectura
1. **Separation of Concerns**: Detector ≠ UI
2. **Proposal Pattern**: Draft → Approve/Reject
3. **Modular Detection**: Cada tipo independiente
4. **Async Detection**: No bloquea UI
5. **Backward Compatibility**: Overloading
